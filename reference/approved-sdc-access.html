Sign in to the Solutions Demo Center

Labs 11–12 move to a separate, pre-configured SDC tenant containing activity data for analysis and workflow exercises.

Applies to: Labs 11–12 Access: Read-only administrator Environment: Pre-built
!
Do not use your learner tenant for Labs 11–12

The Solutions Demo Center (SDC) is separate from the unique tenant used in Labs 1–10. Use the SDC credentials supplied for the course when you reach this checkpoint.

What you need

Use the SDC credentials from your access information

The SDC access information may contain several identities. For the EDU-202 SDC tasks, start with the administrator credentials unless a task specifically tells you to use another identity.

Use these fields

  1. Admin User Login URL — open the administrator SDC sign-in page supplied with your course access information.
  2. Admin Username — use the assigned SDC administrator account.
  3. Password — use the SDC password shown in the same credential block.
  4. Complete 2FA enrollment if the environment prompts for it.
i
Other identities

Additional non-admin identities may be listed for demonstration scenarios. Use them only when a specific lab step instructs you to do so.

Different lab model

Analyze an existing environment
