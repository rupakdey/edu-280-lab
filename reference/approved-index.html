Course outcome

What you will practice

Concise objectives replace the long scenario narrative in the source guide.

01

Access

Deliver secure access for users and third parties with Browser Access, ZPA, Privileged Remote Access, and Zero Trust Browser.

Monitor digital experience, run diagnostics, automate with OneAPI, analyze reports, and work with incident workflows.

Experience Center navigation

Use the new navigation throughout this web guide

The menu structure is changing; the policy and resource configuration itself is not.

i
Navigation transition

The Experience Center currently allows users to switch between Original and New navigation from Account Settings. The original navigation option is scheduled to be removed after 1:00 AM UTC on October 29, 2026. This web guide uses the New navigation as its baseline.

✓
What changes — and what does not

Only the menu/navigation structure changes. The underlying ZIA, ZPA, ZDX, Browser, App Connector, policy, resource, and other configuration objects continue to work the same way.

VM

Your Skytap pod

Each participant also receives a unique Skytap link. It gives you access to the virtual machines used in the hands-on labs and expires with the session.

  • Corp: Client PC 1 — learner workstation
  • Corp: Win Svr — directory, DNS, CA, and internal services
  • Corp: Docker Server — HVAC, DVWA, and simulated SIEM workloads
  • Corp: ZPA Connector — private application connectivity
  • Corp: Log Streaming Connector — log-streaming path

Keep your original access information available during the course; it is the authoritative source for your assigned tenant identity, Skytap URL, and session password.

i
Solutions Demo Center is separate

Labs 11–12 switch to a read-only Solutions Demo Center (SDC) tenant that already contains activity data for analysis. A dedicated access checkpoint appears immediately before Lab 11 so learners do not need to remember SDC details from the beginning of the course.
